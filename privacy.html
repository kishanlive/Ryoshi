🔒 Privacy Policy

Last Updated: November 11, 2026

1. Introduction

This Privacy Policy explains how Ryoshi ("the Bot", "we", "us") collects, processes, and protects your information when you use our Discord bot services. We are fully committed to protecting user privacy and strictly adhering to the Discord Developer Policy and Discord Terms of Service.

2. Information We Collect and Process

2.1 Automatically Collected Data

  • User IDs: Discord Snowflake user IDs for executing playback commands and managing personal playlists.
  • Server IDs: Discord Snowflake server (guild) IDs to persist server-specific preferences (such as custom prefixes, theme colors, and request channels).
  • Channel IDs: Voice and text channel IDs to stream requested audio and send playback embeds.
  • Command Usage & Interaction Data: Button interaction and command timestamps used strictly to diagnose technical faults and maintain uptime.

2.2 User-Provided Data

  • Saved Playlists: Custom playlist names and track URLs voluntarily saved by users via playlist commands (e.g. /playlist create).
  • Server Configurations: Custom server settings configured by server administrators (custom prefix, default volume, autoplay, song-request channel ID).
  • Search Queries: Track titles or URLs submitted for real-time music search.

2.3 Discord Gateway Intents & Message Content

Privileged Gateway Intent Disclosure: Ryoshi requests Discord's Message Content Intent solely to enable real-time music playback features. We handle all message data strictly in accordance with Discord's Privileged Intent guidelines:

  • Dedicated Song-Request Channel: When a server administrator configures a dedicated request channel via /setup, members can type song names or paste media links directly into chat. Ryoshi reads the message content solely in-memory to extract the audio search query, queues the requested song, and immediately triggers Discord API message deletion to keep the text channel clean.
  • In-Chat Prefix Commands: For servers and mobile users utilizing text prefix commands (e.g., .play <query>, .skip, .queue), message content is parsed strictly in-memory to match recognized bot commands.
  • Strict Ephemeral Processing: Message content is processed in volatile memory (RAM) in real time and is never logged, never saved to persistent storage or databases, and never transmitted off-platform.
  • No Machine Learning or AI Training: Message content is NEVER used to train artificial intelligence (AI), machine learning (ML), or language models.
  • No Private Messages or General Chat Monitoring: Ryoshi never reads, logs, or intercepts direct messages (DMs) or general server conversation unrelated to bot commands.

2.4 Data We Do NOT Collect or Store

  • Message content (outside the ephemeral in-memory command parsing described above)
  • Voice recordings, spoken audio, or microphone streams (voice gateway is strictly one-way transmit for audio output)
  • Private user chat logs or personal communications
  • Personally Identifiable Information (real names, physical addresses, IP addresses, email addresses)
  • Financial, billing, or payment data

3. How We Use Your Information

We use collected data to:

  • Provide music playback functionality
  • Save your playlists and preferences
  • Maintain server-specific settings
  • Improve Bot performance and features
  • Cache frequently played songs for faster loading

4. Data Storage and Security

4.1 Storage

  • Data is stored in local SQLite databases
  • Playlist data is stored in JSON format
  • No cloud storage of personal data

4.2 Security

  • We implement reasonable security measures
  • Access to databases is restricted
  • Data is not encrypted but stored locally

4.3 Retention

  • Playlist data: Stored until manually deleted by users
  • Server settings: Stored until Bot is removed from server
  • Song cache: Temporary storage, cleared periodically

5. Third-Party Services

5.1 Music Sources

The Bot uses:

  • YouTube: For music resolution and playback (subject to YouTube's Privacy Policy)
  • Spotify: For track/album/playlist metadata retrieval (subject to Spotify's Privacy Policy)
  • SoundCloud, Apple Music & Deezer: For audio streaming and track resolution (subject to their respective Privacy Policies)
  • Lavalink: High-performance self-hosted audio streaming server

5.2 Data Sharing

We do NOT:

  • Sell, monetize, or broker user data to third parties
  • Share personal information or server data with advertisers
  • Use user data or message content to train machine learning or AI models
  • Retain or distribute chat messages or voice streams

We MAY share data only:

  • If strictly required by law, subpoena, or legal process
  • To protect our legal rights, infrastructure security, or safety

6. Your Rights, Choices & Opt-Out

You have complete control over your data:

  • Access: View your saved playlists at any time using /myplaylist
  • Delete: Permanently delete your saved playlists with /delete_playlist
  • Message Content Opt-Out: Users and servers who prefer not to use Message Content can use Discord's native Slash Commands exclusively (e.g. /play) and avoid configuring a dedicated song-request channel. Message content is never tracked, stored, or logged under any circumstance.
  • Complete Data Erasure: Removing the Bot from your Discord server or requesting data deletion via our support server completely erases all server-associated configuration data.
